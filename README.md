# Chrono Web

Application chrono simple (HTML/CSS/JS), prete pour GitHub.

## Fonctionnalites

- Start / Stop / Reset
- Lap (historique des tours)
- Affichage en centiemes
- Fonctionne sans backend

## Structure

- `index.html`
- `style.css`
- `app.js`

## Lancer en local

Ouvre simplement `index.html` dans le navigateur.

## Publier sur GitHub

```bash
git add .
git commit -m "feat: chrono web app"
git push
```

## Activer GitHub Pages

1. Ouvrir `Settings` du repo GitHub
2. Aller dans `Pages`
3. Dans `Build and deployment`, choisir `Deploy from a branch`
4. Selectionner la branche `main` et le dossier `/ (root)`
5. Sauvegarder

Ton appli sera en ligne sur l'URL GitHub Pages du repo.
